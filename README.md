# California Department of Healthcare Services; Initiative on Healthcare Associated Infections
The following dashboard was created in HPM 749: Data Visualization in Public Health. The dashboard aims to support infection prevention efforts and inform public health strategies, through comparing infection rates, identifying patterns over time, and visualizing prevalence. This mock visualization is meant to provide an example of a centralized resource that aids in understanding the burden and rate of HAIs in California's healthcare system.
